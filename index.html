Latitude-to-radius calibration

r / R = ((90° − φ) / 180°)p
x = r · cos(λ)
y = −r · sin(λ)
LatitudeRadius / RDisk %

All coastlines, grid rings, clicks, and flat-plane measurements follow the selected exponent. p = 1 gives equal radial spacing between latitude degrees. Greenwich (0°) is at the right; east longitudes run counter-clockwise, matching the printed Gleason sheet. This is a configurable display convention, not proof of a physical Earth model.
